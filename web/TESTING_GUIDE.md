# คู่มือการใช้งานระบบทดสอบอัตโนมัติ (Automated Testing Guide)

ระบบนี้ใช้ **Playwright** ในการจำลองการเปิดเว็บและกดปุ่มต่างๆ เพื่อตรวจสอบว่าระบบยังทำงานถูกต้องหรือไม่ครับ

## 1. เตรียมความพร้อม (Prerequisite)
ก่อนรันเทส **ต้องเปิดระบบให้ครบทุกตัวก่อน** (เหมือนตอนใช้งานจริง):
1.  **Backend Server**: `node server/index.js` (Port 3001)
2.  **Frontend (Admin)**: `npm run dev` (Port 5173)
3.  **Map Server**: `node server.js` (Port 3000)

*(ถ้าเปิดทิ้งไว้อยู่แล้ว ก็ข้ามไปข้อ 2 ได้เลยครับ)*

---

## 2. วิธีรันเทส (Run Tests)

เปิด Terminal ใหม่ แล้วพิมพ์คำสั่งตามต้องการ:

### 🟢 วิธีที่ 1: รันแบบเงียบ (รวดเร็ว)
เหมาะสำหรับเช็คเร็วๆ ว่ามีอะไรพังไหม
```bash
npx playwright test
```
- ถ้าขึ้น **Passed** สีเขียวหมด = ระบบปกติ ✅
- ถ้าขึ้น **Failed** สีแดง = มีจุดที่พัง ❌

### 🟡 วิธีที่ 2: รันแบบมีหน้าจอควบคุม (แนะนำสำหรับมือใหม่ ⭐)
วิธีนี้จะเปิดหน้าต่างโปรแกรมขึ้นมา ให้คุณเห็นรายการเทสและกดเล่นดูได้
```bash
npx playwright test --ui
```
- คุณสามารถกดปุ่ม ▶️ หลังชื่อเทสเพื่อดูมันทำงานแบบสดๆ ได้
- เห็นหน้าจอ Browser ที่มันเปิดขึ้นมาจริงๆ

### 🔴 วิธีที่ 3: ดูรายงานผล (Report)
ถ้าเทสเสร็จแล้วอยากดูสรุปสวยๆ
```bash
npx playwright show-report
```

---

## 3. ไฟล์เทสอยู่ที่ไหน?
ถ้าอยากแก้หรือเพิ่มเทส ไฟล์จะอยู่ในโฟลเดอร์ `tests/` ครับ:
- `tests/admin-dashboard.spec.js`: เช็คหน้า Admin
- `tests/overlays.spec.js`: เช็คหน้า Overlay ต่างๆ
- `tests/random-map.spec.js`: เช็คระบบสุ่มแมพ

คุณสามารถเข้าไปแก้ไขไฟล์พวกนี้เพื่อเปลี่ยนเงื่อนไขการตรวจสอบได้ครับ
